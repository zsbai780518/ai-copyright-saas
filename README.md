## 📖 项目简介

本系统为 **SaaS 化全自动 AI 版权侵权舆情管控系统**，基于多模态 AI 搜索引擎 + 分布式合规爬虫，专注解决企业/个人商标权、著作权、原创文字、图片、短视频等数字权益侵权监测问题。

实现 **7×24 小时全自动全网检索**、侵权识别、证据固化、预警通知、Word 报告自动生成与导出，为用户提供一站式数字权益维权管控服务。

### 🎯 核心定位

- **文字侵权监测**: 原创文章、文案、广告语、商标关键词、商号的盗用、洗稿、冒用
- **图片侵权监测**: 原创 LOGO、摄影图、设计图、插画的裁剪、去水印、盗用、商用
- **视频侵权监测**: 原创短视频、口播视频、课程视频的搬运、混剪、片段盗用、音频抄袭

## 🚀 快速开始

### 环境要求

- JDK 17+
- Node.js 18+
- MySQL 8.0+
- Redis 7.0+
- Maven 3.8+

### 1. 克隆项目

```bash
git clone https://github.com/zsbai780518/ai-copyright-saas.git
cd ai-copyright-saas
```

### 2. 数据库初始化

```bash
# 创建数据库
mysql -u root -p -e "CREATE DATABASE ai_copyright_saas DEFAULT CHARACTER SET utf8mb4;"

# 导入表结构
mysql -u root -p ai_copyright_saas < database/schema.sql
```

### 3. 后端启动

```bash
cd backend

# 修改配置文件 src/main/resources/application.yml
# 配置 MySQL、Redis、Elasticsearch 连接信息

# 编译打包
mvn clean package -DskipTests

# 启动服务
java -jar target/ai-copyright-saas-1.0.0.jar

# 或使用 Maven 直接运行
mvn spring-boot:run
```

服务启动后访问：http://localhost:8080/api

### 4. 前端启动

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

前端访问：http://localhost:3000

### 5. 默认账号

```
用户名：admin
密码：admin123
```

### 主要接口

| 模块 | 接口 | 说明 |
|------|------|------|
| 认证 | POST /api/auth/login | 用户登录 |
