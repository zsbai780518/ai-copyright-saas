## 1. 系统介绍

### 1.1 产品概述

AI 版权侵权舆情管控 SaaS 系统是一款专注于数字权益保护的智能监测平台，通过 AI 技术实现 7×24 小时全自动全网侵权监测。

### 1.2 适用人群

- 企业知识产权管理人员
- 品牌运营人员
- 内容创作者
- 律师事务所
- 知识产权保护机构

### 1.3 核心优势

- ✅ **全自动运行** - 一次配置，全程自动
- ✅ **多模态识别** - 文字/图片/视频全覆盖
- ✅ **SaaS 化服务** - 无需部署，登录即用
- ✅ **证据合规** - 自动固化，满足维权需求
- ✅ **报告专业** - Word 报告，直接用于投诉

## 2. 快速入门

### 2.1 系统访问

**访问地址：** http://localhost:3000（本地部署）或您的域名

### 2.2 账号注册

1. 点击「注册账号」按钮
2. 填写用户名、密码、手机号
3. 填写企业/组织名称（可选）
4. 点击「注册」按钮
5. 注册成功后自动登录

### 2.3 首次登录

1. 输入用户名和密码
2. 点击「登录」按钮
3. 进入系统控制台

**默认管理员账号：**
- 用户名：admin
- 密码：admin123

## 3. 功能操作指南

### 3.1 控制台首页

登录后进入控制台首页，显示：

- 原创资产总数
- 监测任务数量
- 今日检索次数
- 侵权记录数量
- 最近侵权预警列表

### 3.2 原创资产管理

#### 3.2.1 添加文字资产

1. 点击左侧菜单「原创资产」
2. 选择「文字资产」标签页
3. 点击「新增资产」按钮
4. 填写资产信息：
   - 资产名称（如：品牌名称）
   - 类型（品牌词/商标词/原创文案/文章全文）
   - 内容（输入文字内容）
   - 关键词（多个用逗号分隔）
5. 点击「确定」保存

#### 3.2.2 批量导入文字资产

1. 准备 Excel 或 TXT 文件
2. 按照模板格式填写
3. 点击「批量导入」按钮
4. 选择文件上传
5. 系统自动解析并导入

#### 3.2.3 添加图片资产

1. 点击「图片资产」标签页
2. 点击「新增资产」按钮
3. 上传 LOGO 或图片文件
4. 填写资产名称和类型
5. 系统自动提取特征指纹

#### 3.2.4 添加视频资产

1. 点击「视频资产」标签页
2. 点击「新增资产」按钮
3. 上传视频文件
4. 填写资产名称
5. 系统自动抽取关键帧和音频指纹

### 3.3 监测任务管理

#### 3.3.1 创建监测任务

1. 点击左侧菜单「监测任务」
2. 点击「创建任务」按钮
3. 填写任务信息：
   - 任务名称（如：品牌词监测）
   - 资产类型（文字/图片/视频）
   - 选择要监测的资产
   - 勾选监测平台（微信、抖音、微博等）
   - 设置监测频率（实时/小时级/每日/每周）
   - 设置侵权判定阈值（默认 0.8）
4. 点击「创建」按钮

#### 3.3.2 启动/暂停任务

1. 在任务列表中找到目标任务
2. 点击「启动」或「暂停」按钮
3. 任务状态实时更新

**任务状态说明：**
- 🟢 运行中 - 任务正在执行监测
- ⚪ 已暂停 - 任务已暂停
- 🔴 已停止 - 任务已终止

#### 3.3.3 查看任务详情

1. 点击任务名称
2. 查看任务配置信息
3. 查看执行统计：
   - 累计检索次数
   - 累计侵权数量
   - 最后运行时间
   - 下次运行时间

#### 3.3.4 删除任务

1. 在任务列表中找到目标任务
2. 点击「删除」按钮
3. 确认删除

### 3.4 侵权记录管理

#### 3.4.1 查看侵权记录

1. 点击左侧菜单「侵权记录」
2. 查看侵权记录列表
3. 列表显示：
   - 侵权标题
   - 侵权链接
   - 发布平台
   - 发布时间
   - 相似度
   - 风险等级
   - 处理状态

#### 3.4.2 筛选侵权记录

使用顶部筛选条件：

- **风险等级**：疑似侵权/高度侵权/确认侵权
- **处理状态**：未处理/已处理/已忽略

#### 3.4.3 处理侵权记录

**标记为已处理：**

1. 找到未处理的侵权记录
2. 点击「处理」按钮
3. 填写处理备注（如：已发送律师函）
4. 点击「确定」

**忽略侵权记录：**

1. 找到误判或无需处理的记录
2. 点击「忽略」按钮
3. 记录状态变为「已忽略」

#### 3.4.4 查看证据

1. 找到侵权记录
2. 点击「证据」按钮
3. 查看：
   - 侵权页面截图
   - 页面源码
   - 时间戳证书
   - 侵权链接

### 3.5 报告导出

#### 3.5.1 导出周期报告

1. 点击左侧菜单「报告管理」
2. 选择报告类型（日报/周报/月报）
3. 选择时间范围
4. 点击「导出」按钮
5. 下载 Word 报告

#### 3.5.2 导出单条侵权报告

1. 在侵权记录列表中找到目标记录
2. 点击「导出」按钮
3. 下载单条侵权报告

#### 3.5.3 报告内容

导出的 Word 报告包含：

- 报告单位
- 报告周期
- 生成时间
- 统计概览（检索次数、侵权数量等）
- 侵权详情（标题、平台、链接、相似度）
- AI 分析结论
- 证据截图

### 3.6 白名单管理

#### 3.6.1 添加授权主体白名单

1. 点击左侧菜单「系统设置」
2. 选择「白名单管理」标签页
3. 点击「新增白名单」按钮
4. 选择类型：授权主体
5. 填写授权方名称
6. 填写描述（如：官方合作伙伴）
7. 点击「保存」

#### 3.6.2 添加站点白名单

1. 选择类型：站点
2. 填写站点域名（如：zhihu.com）
3. 填写描述（如：允许合理引用）
4. 点击「保存」

#### 3.6.3 添加内容白名单

1. 选择类型：内容
2. 填写内容关键词或声明
3. 填写描述（如：转载或引用声明）
4. 点击「保存」

### 3.7 系统设置

#### 3.7.1 个人信息

1. 点击右上角用户名
2. 选择「个人设置」
3. 修改：
   - 昵称
   - 头像
   - 手机号
   - 邮箱
4. 点击「保存」

#### 3.7.2 账号安全

1. 点击「账号安全」
2. 修改密码：
   - 输入原密码
   - 输入新密码
   - 确认新密码
3. 点击「修改」

#### 3.7.3 通知设置

1. 点击「通知设置」
2. 配置通知方式：
   - 站内信（默认开启）
   - 短信通知
   - 邮件通知
   - 企业微信 webhook
   - 钉钉 webhook
3. 点击「保存」

#### 3.7.4 子账号管理

1. 点击「子账号管理」
2. 点击「创建子账号」
3. 填写：
   - 用户名
   - 密码
   - 角色（子管理员/操作员/只读账号）
   - 手机号
   - 邮箱
4. 点击「创建」

## 4. 常见问题

### Q1: 如何修改登录密码？

**答：** 点击右上角用户名 → 个人设置 → 账号安全 → 修改密码。

### Q2: 监测任务创建后为什么没有数据？

**答：** 
1. 检查任务是否已启动（状态为「运行中」）
2. 检查监测频率设置，首次执行可能需要等待
3. 检查原创资产是否已正确添加

### Q3: 如何添加更多监测平台？

**答：** 创建或编辑任务时，在「监测平台」选项中勾选需要添加的平台。

### Q4: 侵权判定阈值如何设置？

**答：** 
- 建议值：0.7-0.85
- 阈值越高，判定越严格，误报越少但可能漏报
- 阈值越低，判定越宽松，漏报越少但可能误报

### Q5: 如何导出所有侵权记录？

**答：** 在侵权记录列表页面，使用筛选条件选择全部记录，然后点击「批量导出」按钮。

### Q6: 子账号有什么权限？

**答：**
- **子管理员**：除账号管理外的全部权限
- **操作员**：日常操作权限，无管理权限
- **只读账号**：仅查看权限

### Q7: 报告导出失败怎么办？

**答：**
1. 检查是否有侵权记录
2. 检查时间范围是否正确
3. 刷新页面重试
4. 联系技术支持

### Q8: 如何设置预警通知？

**答：** 系统设置 → 通知设置 → 配置通知方式（短信/邮件/webhook）→ 保存。

### Q9: 白名单有什么作用？

**答：** 白名单用于过滤无需监测的内容：
- 授权主体白名单：自动过滤该主体的侵权信息
- 站点白名单：爬虫自动跳过该类站点
- 内容白名单：标记合理引用，避免重复判定

### Q10: 系统支持哪些浏览器？

**答：** 
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
