## 2. 系统概述

### 2.1 系统定位

本系统为 SaaS 化全自动 AI 版权侵权舆情管控系统，基于多模态 AI 搜索引擎 + 分布式合规爬虫，专注解决企业/个人商标权、著作权、原创文字、图片、短视频等数字权益侵权监测问题。

### 2.2 目标用户

- 企业知识产权管理部门
- 品牌运营团队
- 内容创作者
- 律师事务所
- 知识产权保护机构

### 2.3 核心功能

1. **SaaS 多租户管理** - 账号权限、租户隔离、套餐订阅
2. **原创资产入库** - 文字、图片、视频资产管理
3. **全自动监测** - 定时轮询、全网检索
4. **AI 侵权识别** - 多模态相似度比对
5. **证据固化** - 自动截图、时间戳存证
6. **预警通知** - 多渠道实时通知
7. **报告导出** - Word 报告自动生成

## 4. 功能模块设计

### 4.1 SaaS 多租户管理模块

#### 4.1.1 功能描述

实现多租户隔离、用户权限管理、套餐订阅等功能。

#### 4.1.2 权限级别

| 角色 | 权限说明 |
|------|---------|
| 企业主账号 | 全部权限，可管理子账号和套餐 |
| 子管理员 | 除账号管理外的全部权限 |
| 操作员 | 日常操作权限，无管理权限 |
| 只读账号 | 仅查看权限 |

#### 4.1.3 套餐类型

| 套餐 | 监测频率 | 侵权数量 | 监测平台 | 导出额度 |
|------|---------|---------|---------|---------|
| 基础版 | 每日 | 100 | 5 | 10 |
| 专业版 | 小时级 | 500 | 10 | 50 |
| 旗舰版 | 实时 | 9999 | 99 | 999 |

### 4.2 原创资产入库管理模块

#### 4.2.1 文字资产

- 支持手动输入或批量导入
- AI 自动提取关键词和语义指纹
- 资产类型：品牌词、商标词、原创文案、文章全文

#### 4.2.2 图片资产

- 支持单张或批量上传
- AI 自动提取全局特征、局部特征、水印信息
- 资产类型：LOGO、摄影图、设计图、插画

#### 4.2.3 视频资产

- 支持主流视频格式
- AI 自动抽取关键帧、提取音频指纹、识别字幕
- 生成视频指纹库

### 4.3 全自动侵权监测任务模块

#### 4.3.1 任务配置

- 选择监测资产
- 勾选监测平台
- 设置监测频率
- 设置侵权判定阈值

#### 4.3.2 监测频率

| 频率 | 执行间隔 |
|------|---------|
| 实时 | 5 分钟 |
| 小时级 | 1 小时 |
| 每日 | 24 小时 |
| 每周 | 7 天 |

#### 4.3.3 监测平台

- 短视频平台：抖音、快手、视频号
- 自媒体平台：微信公众号、微博、知乎、简书
- 电商平台：淘宝、京东、拼多多
- 搜索引擎：百度、搜狗、必应

### 4.4 侵权识别与证据固化模块

#### 4.4.1 侵权判定

| 风险等级 | 相似度范围 | 说明 |
|---------|-----------|------|
| 疑似侵权 | 60%-75% | 可能存在侵权 |
| 高度侵权 | 75%-90% | 较大可能侵权 |
| 确认侵权 | 90%-100% | 高度确认侵权 |

#### 4.4.2 证据固化

- 自动截图保存
- 页面源码保存
- 链接永久留存
- 时间戳认证

#### 4.4.3 预警通知

- 站内信
- 短信通知
- 邮件通知
- 企业微信/钉钉 webhook

### 4.5 自动报告生成与导出模块

#### 4.5.1 报告类型

- 日报
- 周报
- 月报
- 自定义周期报告

#### 4.5.2 报告内容

- 监测概况
- 全网检索数据
- 侵权统计
- 侵权详情
- 证据截图
- AI 分析结论

#### 4.5.3 导出格式

- Word (.docx)
- PDF（可选）

## 5. 数据库设计

### 5.1 数据库表清单

| 表名 | 说明 |
|------|------|
| tenant | 租户表 |
| user | 用户表 |
| subscription_plan | 套餐表 |
| asset_text | 文字资产表 |
| asset_image | 图片资产表 |
| asset_video | 视频资产表 |
| monitor_task | 监测任务表 |
| infringement_record | 侵权记录表 |
| evidence | 证据表 |
| whitelist | 白名单表 |
| operation_log | 操作日志表 |
| notification | 通知记录表 |

### 5.2 核心表结构

#### 5.2.1 租户表 (tenant)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 租户 ID（主键） |
| tenant_code | VARCHAR(32) | 租户编码 |
| tenant_name | VARCHAR(100) | 租户名称 |
| contact_name | VARCHAR(50) | 联系人 |
| contact_phone | VARCHAR(20) | 联系电话 |
| contact_email | VARCHAR(100) | 联系邮箱 |
| subscription_plan_id | BIGINT | 套餐 ID |
| subscription_start_time | DATETIME | 套餐开始时间 |
| subscription_end_time | DATETIME | 套餐结束时间 |
| status | TINYINT | 状态：0-禁用，1-正常 |

#### 5.2.2 用户表 (user)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 用户 ID（主键） |
| tenant_id | BIGINT | 租户 ID |
| username | VARCHAR(50) | 用户名 |
| password_hash | VARCHAR(255) | 密码哈希 |
| nickname | VARCHAR(50) | 昵称 |
| phone | VARCHAR(20) | 手机号 |
| email | VARCHAR(100) | 邮箱 |
| role | TINYINT | 角色：1-企业主账号，2-子管理员，3-操作员，4-只读账号 |
| status | TINYINT | 状态：0-禁用，1-正常 |

#### 5.2.3 监测任务表 (monitor_task)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 任务 ID（主键） |
| tenant_id | BIGINT | 租户 ID |
| task_name | VARCHAR(100) | 任务名称 |
| asset_type | TINYINT | 资产类型：1-文字，2-图片，3-视频 |
| asset_ids | VARCHAR(500) | 关联资产 ID 列表 |
| monitor_platforms | TEXT | 监测平台列表 |
| monitor_frequency | TINYINT | 监测频率：1-实时，2-小时级，3-每日，4-每周 |
| infringement_threshold | DECIMAL(5,2) | 侵权判定阈值 |
| status | TINYINT | 状态：0-暂停，1-运行中，2-已停止 |
| total_scan_count | BIGINT | 累计检索次数 |
| total_infringement_count | BIGINT | 累计侵权数量 |

#### 5.2.4 侵权记录表 (infringement_record)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 记录 ID（主键） |
| tenant_id | BIGINT | 租户 ID |
| task_id | BIGINT | 任务 ID |
| asset_id | BIGINT | 资产 ID |
| infringement_url | VARCHAR(500) | 侵权链接 |
| infringement_title | VARCHAR(200) | 侵权标题 |
| publish_account | VARCHAR(100) | 发布账号 |
| publish_platform | VARCHAR(50) | 发布平台 |
| similarity_score | DECIMAL(5,2) | 相似度分数 |
| risk_level | TINYINT | 风险等级：1-疑似，2-高度，3-确认 |
| process_status | TINYINT | 处理状态：0-未处理，1-已处理，2-已忽略 |

## 7. 安全设计

### 7.2 数据安全

- 多租户数据字段隔离
- 敏感数据加密存储
- SQL 注入防护
- XSS 攻击防护

### 7.3 接口安全

- 接口限流
- 参数校验
- 权限验证
- 操作日志记录

### 7.4 部署安全

- 非 root 用户运行
- 最小权限原则
- 防火墙配置
- HTTPS 加密传输

## 8. 部署说明

### 8.1 环境要求

| 组件 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 2 核 | 4 核+ |
| 内存 | 4GB | 8GB+ |
| 磁盘 | 20GB | 50GB+ SSD |
| 带宽 | 5Mbps | 10Mbps+ |

### 8.2 软件依赖

- JDK 17+
- MySQL 8.0+
- Redis 7.0+
- Nginx（可选）

### 8.3 部署方式

#### 方式一：本地部署

```bash
# 1. 初始化数据库
mysql -u root -p < database/schema.sql

# 2. 启动后端
cd backend && mvn spring-boot:run

# 3. 启动前端
cd frontend && npm install && npm run dev
```

#### 方式二：Docker 部署

```bash
# 一键启动所有服务
docker-compose up -d
```
