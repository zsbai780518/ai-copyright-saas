## 📋 使用指南

### 步骤 1：填写申请表

打开 `01_软件著作权申请表.md`，填写以下信息：

- 著作权人信息（姓名/名称、证件号码、地址等）
- 开发者信息
- 开发完成日期和首次发表日期
- 签字盖章

### 步骤 2：准备源代码

`02_源代码文档.md` 已包含核心代码示例，您需要：

1. 补充完整前后各 30 页源代码
2. 确保每页不少于 50 行
3. 添加页眉（软件名称 + 版本号）
4. 添加页脚（页码）

### 步骤 3：打印文档

以下文档需要打印：

- 软件著作权申请表（1 份）
- 源代码文档（1 份）
- 软件设计说明书 或 用户手册（1 份，二选一）
- 权利归属证明（1 份）

### 步骤 4：准备身份证明

- **个人申请：** 身份证正反面复印件（签字）
- **单位申请：** 营业执照复印件（加盖公章）

### 步骤 5：装订提交

1. 左侧装订所有材料
2. 检查材料完整性
3. 现场提交或邮寄提交

---

## ⚠️ 注意事项

### 填写要求

1. 所有签字处必须手写签名，不得打印
2. 单位申请需加盖公章
3. 使用 A4 纸打印，双面打印
4. 页眉页码标注清晰

### 源代码要求

1. 提供前后各连续 30 页，共 60 页
2. 不足 60 页需全部提交
3. 每页不少于 50 行（结束页可少于 50 页）
4. 不包含空行和注释（或注释不超过 20%）
5. 页眉标注软件名称和版本号
6. 页脚标注页码

### 文档要求

1. 软件设计说明书或用户手册（二选一）
2. 不少于 30 页
3. 页眉标注软件名称和版本号
4. 页脚标注页码
